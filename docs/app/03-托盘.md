# 03 - 系统托盘

> 2026-09-16。常驻菜单栏托盘：图标 + 右键菜单，macOS 图标旁实时显示今日 token 用量（K/M/E 缩写）。实现参考 mistrelle 的 `src/main/src/app/tray.ts`。

## 实现思路

- 托盘模块独立于窗口：`whenReady` 中 `createMainWindow()` 之后调用 `registerAppTray()`，模块内自持 `Tray` 单例。
- 今日用量数据源：复用 `usageRepo.listUsageByRange(todayKey(), todayKey())`（写入时已按 `日期 × 模型` 累加，无需新增聚合查询），reduce `totalTokens` 即今日总量。选 `usage_daily` 而非 `logRepo.getTodayStats()`（request_logs 会被清理）。
- 刷新时机（双通道）：
  1. **即时**：`proxyHandler.addUsageQuietly()` 落库成功后调用 `refreshTrayUsage()`，请求完成菜单栏数字立即变化；
  2. **兜底**：托盘模块内 `setInterval(refreshTrayUsage, 30_000)`，覆盖跨天归零（`todayKey()` 每次重算）等场景。
- 平台差异：`tray.setTitle()` 仅 macOS（及部分 Linux）在图标旁渲染文字；Windows 不支持，用量只进 tooltip（`AI Router · 今日 xx tokens`）。

## K/M/E 格式口径

`formatTokens(n)`（`src/common/utils/format.ts`，渲染层 `utils/format.ts` re-export，概览页/用量页同步生效）：

| 区间 | 输出示例 | 说明 |
|------|----------|------|
| `< 1 000` | `940` | 原样 |
| `1e3 ≤ n < 1e6` | `1.2K` | K = 千 |
| `1e6 ≤ n < 1e8` | `3.4M` | M = 百万 |
| `≥ 1e8` | `1.5E` | E = 亿（1e8 起档） |

一位小数，结尾 `.0` 去掉（`1000` → `1K` 而非 `1.0K`）。E 档阈值 1e8 与「E 代表几亿」一致。

## 注意事项

- 托盘图标用 `@resources/icon.png?asset` 运行时 `resize`，未单独出 16px 资源；若日后觉得菜单栏观感不佳，可仿 mistrelle 增加独立 `icon16.png`（建议 template image 适配深浅色菜单栏）。
- `refreshTrayUsage()` 内部自捕获异常，`proxyHandler` 调用处无需再包 try/catch。
- macOS 挂 `setContextMenu` 后左键单击也弹菜单（Electron 行为），「打开主窗口」即走菜单项。
