# 03 - 系统托盘

> 2026-09-16。常驻菜单栏托盘：图标 + 统计面板弹窗，macOS 图标旁实时显示今日 token 用量（K/M/E 缩写）。面板的卡片与图表实现详见 `04-统计看板.md`。实现参考 mistrelle 的 `src/main/src/app/tray.ts`。

## 实现思路

- 托盘模块独立于窗口：`whenReady` 中先 `registerAppTray()` 再按是否登录项自启决定建不建主窗口（开机自启静默驻留时也必须有托盘），模块内自持 `Tray` 单例。
- 今日用量数据源：`usageRepo.listUsageByRange(todayKey(), todayKey())`（写入时已按 `日期 × 供应商 × 模型` 累加，reduce `totalTokens` 即今日总量）。选 `usage_daily` 而非 `logRepo.getTodayStats()`（request_logs 会被清理）。
- 刷新时机（双通道）：
  1. **即时**：`proxyLog.recordRequest()` 落库成功后调用 `refreshTrayUsage()`，请求完成菜单栏数字立即变化；
  2. **兜底**：托盘模块内 `setInterval(refreshTrayUsage, 30_000)`，覆盖跨天归零（`todayKey()` 每次重算）等场景。
- 平台差异：`tray.setTitle()` 仅 macOS（及部分 Linux）在图标旁渲染文字；Windows 不支持，用量只进 tooltip（`AI Router · 今日 xx tokens`）。

## 统计面板（弹出窗口）

原生托盘菜单只能渲染纯文字，放不下热力图 / 环形图 / 进度条，故统计面板是**独立的小窗口**（`trayPanel.ts`）：

| 项 | 取值 |
|----|------|
| 尺寸 | 400 × 640，`resizable: false`、`alwaysOnTop`、`skipTaskbar`、`frame: false` |
| 外壳 | darwin `vibrancy: 'popover'` + 透明底；win32 `backgroundMaterial: 'acrylic'`；linux 实色 `#F4F4F4` |
| 叠加层 | 渲染层面板底与卡片底均半透明，把原生材质透出来（见「面板外观：亚克力三层结构」） |
| 生命周期 | 单实例，隐藏而非销毁（点击响应快、图表状态保留），`blur` 自动隐藏 |
| 渲染入口 | `src/renderer/tray.html` → `windows/tray/main.ts`（electron-vite `rollupOptions.input` 多入口） |
| 内容 | 复用 `components/usage/UsageDashboard.vue`（compact 模式），维度为 近24小时 / 近七天 / 近30天 |

定位：按 `tray.getBounds()` 水平居中于图标下方，贴边时回夹进 workArea；下方空间不足（如任务栏/Dock 在下方）改在图标上方展开。

## 面板外观：亚克力三层结构

> 2026-09-17。面板的亚克力是「原生材质 + 两层渲染层叠加」出来的，**只有渲染层两层可调**。

| 层 | 位置 | 取值 |
|----|------|------|
| 原生材质 | `src/main/src/app/trayPanel.ts` | darwin `vibrancy: 'popover'` + `visualEffectState: 'active'`；win32 `backgroundMaterial: 'acrylic'`；两者均 `backgroundColor: '#00000000'`；linux 无材质（窗口实色 `#F4F4F4`） |
| 面板底 | `windows/tray/App.vue` 的 `.panel` | `--fluent-acrylic-bg`：浅 `rgba(255,255,255,0.6)` / 暗 `rgba(32,31,30,0.6)`（定义在 `assets/style/theme.less`，全仓库只有托盘面板消费） |
| 卡片底 | `components/usage/MetricCard.vue` 的 `.metric-card` | `--fluent-card-bg`，被面板作用域重定向为 `--fluent-acrylic-card-bg`：浅 `rgba(255,255,255,0.5)` / 暗 `rgba(255,255,255,0.08)` |

要点：

- **alpha 必须留白**：原生材质在渲染层之下，面板底一旦接近不透明（原值 0.85）材质就完全看不见。0.6 / 0.5 是「材质可见」与「文字可读」的折中；想更透/更实只改这两个 token。
- **卡片要比面板更实**才是浮起：浅色靠更高的 alpha（0.6 面板上叠 0.5 白 ≈ 0.8 合成），暗色靠一层白色薄膜 + 既有 hairline 描边与阴影（Fluent 暗色卡片口径）。
- **重定向而非写死**：面板只在 `.panel` 上把 `--fluent-card-bg` 指向玻璃底，CSS 变量随 DOM 继承到面板内所有卡片（`UsageDashboard` → `MetricCard`），不泄漏到主窗口（主窗口容器是不透明的 `--td-bg-color-container`，卡片换成 0.7 alpha 后合成结果不变）。
- **渐晕要跟着半透明**：`--metric-tint` 是不透明色阶，`customer.less` 用 `color-mix` 经 `--metric-tint-alpha`（默认 100%）降透明度，面板给 60%，否则卡片右上角会糊出一块实色。
- **loading 遮罩在托盘里去掉**（2026-09-17）：面板每次弹出都会 `tray:shown` → 重新取数，原来每次都盖一层遮罩。遮罩底色 `--td-mask-disabled` 确实是半透明的（浅 `rgba(255,255,255,0.6)` / 暗 `rgba(0,0,0,0.4)`，见 `theme.less`），**去掉的理由不是「不透明」，而是「每次弹出都整块盖一下」在亚克力上太跳**：紧凑模式传 `:show-overlay="false"`（只留 spinner）+ `:delay="200"`（快速请求完全不闪），首页保持原生遮罩。
- 面板内的 tdesign 控件分两类：**状态胶囊保持不透明**（Fluent 弹窗里的控件本就比底更实）；**维度分段控件改为半透明轨道 + 玻璃缩略块**（`.fluent-segmented`，2026-09-17 修订，详见 `09-看板卡片规范.md`）—— 它是面板里面积最大、位置最靠上的控件，`variant="outline"` 的不透明底 + 硬边框在亚克力面上是唯一的实色块。
- 主进程窗口参数无需改动，也不加 `transparent: true`（Windows 上与 `backgroundMaterial` 冲突）；圆角与阴影交给系统（macOS `roundedCorners` 默认开启）。

已知限制：

- 原生材质跟随**系统**主题：未同步 `nativeTheme.themeSource`（会破坏「跟随系统」判定并影响 `titleBarOverlay`），所以把外观强制成与系统相反的深浅色时，面板底色会比预期偏亮/偏暗。
- linux 无原生模糊：窗口实色 + 渲染层半透明叠加 → 退化成浅灰面板（与改造前观感一致）。
- Windows 上 acrylic 能否真正透出取决于原生材质（与主窗口同一套配方），Windows 10 无该材质时面板会偏灰。

## 托盘交互（平台分支）

| 平台 | 左键 | 右键 |
|------|------|------|
| darwin / win32 | 切换统计面板（已显示则收起） | `popUpContextMenu`：打开统计面板 / 打开主窗口 / 退出 |
| linux | —（多数桌面环境不派发 tray click） | `setContextMenu`，同样三项 |

**关键约束**：macOS 上不能同时 `setContextMenu`，否则菜单会吞掉左键点击，面板永远弹不出来；因此 darwin/win32 走 `tray.on('click')`，菜单只在右键时手动弹出。

## K/M/E 格式口径

`formatTokens(n)`（`src/common/utils/format.ts`，渲染层 `utils/format.ts` re-export，看板同步生效）：

| 区间 | 输出示例 | 说明 |
|------|----------|------|
| `< 1 000` | `940` | 原样 |
| `1e3 ≤ n < 1e6` | `1.2K` | K = 千 |
| `1e6 ≤ n < 1e8` | `3.4M` | M = 百万 |
| `≥ 1e8` | `1.5E` | E = 亿（1e8 起档） |

一位小数，结尾 `.0` 去掉（`1000` → `1K` 而非 `1.0K`）。E 档阈值 1e8 与「E 代表几亿」一致。

## 注意事项

- 托盘图标用 `@resources/icon.png?asset`（透明底彩色机器人图，托盘专用，与 `build/` 应用图标不同）运行时 `resize` 到 16px（@2x 32px），未单独出 16px 资源；图标来源与再生成见 `06-应用图标.md`。彩色非 template，不随深浅色菜单栏变色。
- `refreshTrayUsage()` 内部自捕获异常，调用处无需再包 try/catch。
- **点击竞态**：点击托盘图标时面板先因失焦隐藏、随后 click 才到达；若只判断可见性会出现「关了又开」。`trayPanel.ts` 用 `lastHideAt`（250ms 抑制窗口）吞掉紧跟隐藏后的这次点击。
- 面板必须 `win.show()` + `focus()`（不能用 `showInactive()`）：失焦自动隐藏依赖 `blur` 事件。
- **数据刷新**：主进程每次弹出面板后经 `webContents.send('tray:shown')` 通知渲染层重新取数（隐藏窗口重新显示时 DOM `focus` 事件不触发，不能用它做刷新时机）。preload 暴露 `trayApi.onShown(cb)`。
- 面板是独立渲染入口，需显式调用 `useColorMode()` 才会应用深浅色；`colorMode.ts` 的 `storage` 事件监听让主窗口切主题后面板即时跟随。
