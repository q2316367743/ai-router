# 管理界面

> 渲染层页面结构：Fluent Design 布局（参考 mistrelle）+ 7 个页面 + 命令式弹窗。所有 UI 用 TDesign（unplugin 按需引入），颜色一律 tdesign CSS Token（UnoCSS shortcut 如 `text-td-secondary`），布局尺寸用 unocss 工具类。统计看板相关（图表基元 / 共享用量组件 / 首页重写 / 托盘面板）见 `04-统计看板.md`。

## 布局（`windows/main/App.vue`，参考 mistrelle）

- **拖拽区是 fixed 覆盖层**（48px、z-index 52、`-webkit-app-region: drag`），不占文档流；页面 header 的操作按钮区通过更高 z-index + `no-drag` 穿透。
- 根容器 `t-layout.main` 为 `position: fixed` 全屏，背景 `var(--td-bg-color-page)`；显式 `flex-direction: row`（不依赖 TLayout 的 aside 自动检测）。
- **侧边栏可收起**（`src/renderer/src/global/collapsed.ts` 模块级单例 ref）：`t-aside` 宽度 `collapsed ? 0 : 220px`（0.2s 过渡，overflow hidden）；折叠按钮 `.common-operator` fixed 于 `top: 8px; left: l1`（z-index 60、`no-drag`，macOS 让出交通灯），图标 `view-list`。
- **侧边栏**：顶部 32px 占位避开 macOS 交通灯（`trafficLightPosition y=17`），`t-menu` 七项（概览/提供商/模型映射/服务/日志/用量统计/设置，`/` + 路径首段为激活值）。
- **内容区**（`t-content.main-container`）：`height: 100vh` + `border-radius: var(--td-radius-medium)` + `var(--td-bg-color-container)` 背景——浮在 page 背景之上的圆角卡片，overflow hidden。
- 路由（`router.ts`）全部懒加载，`/` 重定向 `/home`。

## 深浅色模式（`src/renderer/src/hooks/colorMode.ts`，参考 mistrelle ColorMode）

- **三态**：`light` / `dark` / `system`（跟随系统 `prefers-color-scheme`，含 `mediaQuery change` 监听实时跟随），`localStorage` 持久化（key `ai-router-color-mode`），默认 `system`。
- **模块级单例**：import 即读取持久化状态并渲染主题（首帧前生效），全组件共享同一状态与监听器。
- **双通道同步**：TDesign token 走 `html[theme-mode="dark|light"]`（fluent `theme.less` 的 token 集按此属性切换），UnoCSS 的 `dark:` 变体走 `html.dark` class，`renderColorMode()` 内两者同步维护。
- **入口**：`App.vue` import 保证初始化；切换 UI 在「设置」页（`pages/settings/index.vue` 外观卡片，`t-radio-group` 三选）。旧 `store/app.ts`（toggleTheme 两态）已删除。

## 设置页（`pages/settings/index.vue`）

三张卡片：「外观」（三态色彩模式 radio，即时生效）、「开机自启」（t-switch 即时切换）、「**网络代理**」（2026-09-17）——上游请求代理 URL 输入框 + 保存按钮（draft 脏状态禁用、回车提交），保存经 `service:saveConfig` 整对象回传（先 getConfig 取全量再展开覆盖 `proxyUrl`）并重启服务，留空直连；后端校验 http(s) URL，生效机制见 `../server/01-本地代理服务.md`。后续全局设置项在此扩展。

## 页面容器 PageLayout（`src/renderer/src/components/PageLayout/PageLayout.vue`）

参考 mistrelle 的通用页面骨架：48px 页头（标题可拖拽 + `extra` 插槽操作按钮，按钮区 `z-index: 53` + `no-drag` 穿透拖拽层）+ 绝对定位滚动内容区 + `t-back-top`。左右 padding 经 `src/renderer/src/hooks/useTitlePadding.ts` 适配：`r1` 避让 Windows titleBarOverlay（macOS 为 0）；侧边栏折叠时（`collapsed` class）页头 `padding-left` 过渡到 `l2`（折叠按钮右侧），标题不被悬浮按钮遮挡。

各页面均以 `<PageLayout title="…"><template #extra>操作</template>内容</PageLayout>` 组织。

公共工具 `src/renderer/src/utils/format.ts`：`formatTime` / `formatDateTime`（MM-DD HH:mm:ss）/ `formatTokens`（940→1.2k→3.4M）/ `formatDuration`（ms→s，null 返回 `-`）/ `isSuccessStatus`（2xx，null 不算成功）/ `isPendingStatus`（status 为 null 即进行中）/ `maskKey` / `statusTheme`（HTTP 状态 → tag theme）。

日志页私有 hook `pages/logs/useLogRefresh.ts`：统一管理日志列表取数，返回 `list/total/loading/now/hasPending/refresh`。刷新来源三路——① `window.preload.log.onChanged` 推送（300ms 防抖后，仅当自动刷新开启 && 第 1 页 && 窗口可见时才重查，避免并发下的刷新风暴）② 30s 轮询兜底（推送丢失、窗口从后台恢复）③ 用户手动刷新/筛选/翻页。并发保护：查询进行中时到来的刷新请求合并为一次补跑，避免旧结果覆盖新结果。进行中行需要实时耗时，故维护 `now` 时间戳：**仅在列表存在进行中行时**启动 1s 计时器，全部结束后立即停掉（空闲零开销）。

日志页私有组件 `pages/logs/components/`：`LogExpandedRow`（行展开详情，按 `log:getDetail` 拉全量；进行中显示提示条，且 `pending` 由真变假时自动重拉以显示回填结果）、`LogPayloadPanel`（正文/标头切换面板）、`CodeViewer`（Monaco 只读查看器封装，动态加载 + worker + tdesign token 主题）、`JsonView`（JSON 美化 + 解析失败回退纯文本，输出给 `CodeViewer`）、`LogHeaders`（标头 descriptions）。Monaco 接入与 subpath/worker 注意事项见 `05-日志代码查看器.md`。

服务页私有组件 `pages/service/components/ServiceAccessExamples.vue`：`t-card` + `t-tabs`（OpenAI 兼容 curl / Codex `~/.codex/config.toml` / 通用 Agent 环境变量），按当前 endpoint 与 API Key 动态生成代码块，配置区右侧统一「复制」按钮（`#action` 插槽按激活 tab 复制对应示例）。

## 命令式弹窗（两文件模式）

全部 `DialogPlugin`（center、`footer:false`、`destroyOnClose:true`），外壳 `.tsx` 导出 `openXxx(options)` 用 `h()` 渲染内容组件，内容 `.vue` 承载表单/按钮并 `emit('close' | 'success')`：

| 外壳                                        | 内容                  | 用途                                                                                   |
| ------------------------------------------- | --------------------- | -------------------------------------------------------------------------------------- |
| `pages/providers/modals/ProviderDialog.tsx` | `ProviderContent.vue` | 提供商新增/编辑（name/baseUrl/apiKey 可切换明文/enabled）                              |
| `pages/models/modals/ModelDialog.tsx`       | `ModelContent.vue`    | 映射新增/编辑（publicName/提供商 t-select（过滤已禁用，编辑态保留当前）/upstreamName） |

行内启停（`t-switch`）直接调 `provider.update` / `model.update`（携带完整入参），不走弹窗。

## 服务状态推送链路

`proxyServer.updateStatus()` → `webContents.send('server:status')` → preload `serviceApi.onStatusChanged(cb)`（返回退订函数）→ 概览页/服务页订阅；页面 `onMounted` 时另调 `getStatus()` 拉一次初始值，`onUnmounted` 退订。
