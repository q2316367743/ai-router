# ai-router

AI Router —— Electron + Vue 3 + TypeScript 桌面应用。

工程骨架参考 [mistrelle](../../mistrelle) 搭建：TDesign + UnoCSS + 自动导入 + Pinia + Vue Router + drizzle(SQLite)。工程约束见 [AGENTS.md](./AGENTS.md)，技术文档索引见 [docs/README.md](./docs/README.md)。

## 推荐开发环境

- [VSCode](https://code.visualstudio.com/) + [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint) + [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar)

## 项目设置

### 安装

```bash
$ yarn
```

### 开发

```bash
$ yarn dev
```

### 类型检查

```bash
$ yarn typecheck
```

### 打包

```bash
# For windows
$ yarn build:win

# For macOS
$ yarn build:mac

# For Linux
$ yarn build:linux
```
